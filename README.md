# Two Wards

Proof of concept for a real-time co-op tower defense roguelite with a card system, built in Godot 4 with pixel art.

Two wizards defend a Heart Crystal against waves of monsters. Towers, spells and hero abilities come from a shared card deck; runs earn gold for boosters, which feed a persistent collection and deck builder.

The goal of this PoC is to validate the whole pipeline: Godot project structure, AI-assisted coding, automated testing, AI asset generation, online co-op networking (self-hosted lobby + WebRTC P2P), and build/deploy.

See [docs/PLAN.md](docs/PLAN.md) for scope, architecture, card and meta design, asset pipeline, testing strategy and milestones.
